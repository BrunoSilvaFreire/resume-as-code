# Agent Skills

The repository ships four portable skills:

| Skill | Purpose |
| --- | --- |
| `timeline-polishing` | Raw notes to detailed Markdown records and public/private claims |
| `resume-generation` | JD analysis, retrieval, provenance, RenderCV resume, and output review |
| `rendercv` | Official v2.8 schema/CLI contract and rendering boundary |
| `interview-preparation` | Interview guide from a completed application |

`AGENTS.md` is the universal entry point. Skills-compatible agents may link or copy these directories into their project skill location. The optional official RenderCV skill is available from `rendercv/rendercv-skill` and is useful for advanced theme/schema work.
