# External Job Platforms & Sponsoring Employers — 2026-10-12

Companion to the LinkedIn workflow in [`README.md`](README.md). This report
covers **job-search avenues outside LinkedIn**. Every URL in the tables was
fetched on 2026-10-12; status codes and the verification method are recorded in
[Sources](#sources).

**Fit-scoring profile**

Fit columns assume a senior software engineer targeting:

- Remote roles anywhere, or onsite roles with relocation + visa sponsorship
  (Germany, Netherlands, Sweden, Poland, Canada, UK, Ireland, and other EU).
- Role families: (a) backend/platform (Go, Kubernetes, distributed systems,
  observability/OpenTelemetry, SRE); (b) Unreal Engine / real-time rendering /
  graphics / engine programming (C++, shaders, GPU); (c) staff/senior
  generalist.

Adjust the fit column to your own profile.

**Evidence key for sponsorship columns**

- **Explicit** — the employer's own careers/relocation page states visa and/or
  relocation support.
- **Reported** — a third-party aggregator or a government sponsor register
  states the employer sponsors; not confirmed on the employer's own page.
- **Role-dependent** — the employer sponsors on some roles and explicitly does
  *not* on others.
- **Unknown** — no verifiable statement found. Treat as "verify on the role".

## Search strategies

Concrete queries and board filters per role family. Board filter syntax
varies; the queries below are written to be pasted into board search boxes or
the site's own URL filters.

### (a) Backend / platform / SRE (Go, Kubernetes, observability)

- **Titles to search:** `platform engineer`, `backend engineer`, `site
  reliability engineer`, `SRE`, `infrastructure engineer`, `distributed systems
  engineer`, `staff software engineer`, `observability engineer`.
- **Stack keywords:** `Go`, `Golang`, `Kubernetes`, `OpenTelemetry`,
  `Prometheus`, `Grafana`, `Terraform`, `PostgreSQL`, `gRPC`.
- **Remote boards:** We Work Remotely → *Programming* + "DevOps and Sysadmin";
  Remote OK filter `Go`; Remotive "Remote Jobs from Brazil"; Jobgether
  `/remote-jobs/brazil/software-engineer`.
- **EU relocation boards:** Arbeitnow with the **Visa Sponsorship** filter +
  `Kubernetes`/`Go`; Berlin Startup Jobs `/skill-areas/visa-sponsorship`;
  No Fluff Jobs / Just Join IT (Poland) with `Kubernetes`; Next Level Jobs
  per-country pages (DE/NL/SE/PL).
- **Employer-direct:** Grafana Labs (`observability`), GitLab (`Go`,
  `Backend`), Delivery Hero (`Golang`, `Kubernetes`), Zalando (`Platform`,
  `Kubernetes`), Personio (`Platform Engineer`), Revolut (`Kubernetes`).
- **HN:** open https://hnhiring.com and Ctrl+F `Remote`, `Golang`,
  `Kubernetes`, `OpenTelemetry`.

### (b) Unreal Engine / real-time rendering / graphics / engine

- **Titles:** `engine programmer`, `graphics programmer`, `rendering
  engineer`, `rendering programmer`, `graphics engineer`, `engine
  developer`, `tools programmer`, `technical artist (rendering)`.
- **Keywords:** `Unreal Engine`, `UE5`, `C++`, `HLSL`, `shaders`, `Vulkan`,
  `DirectX 12`, `GPU`, `real-time rendering`, `ray tracing`, `compute shaders`.
- **Boards:** WorkinGames `/jobs/roles/engine-programmer`; Remote Game Jobs
  (rendering/graphics filter); Hitmarker (engineering); ASGC Jobs (engineering);
  Games Jobs Direct (programming); gamesJobs UK (programming); Jobs in XR.
- **Studio-direct:** Guerrilla (Decima, Amsterdam), CD Projekt Red
  (Warsaw), Epic Games (Unreal, UK/CA), King, Nixxes, Avalanche, Massive,
  Remedy, Larian, Techland.
- **Remote-India-style bands to watch:** Work With Indies tags roles by
  timezone (e.g. `CET ± 4`) — good for a Brazil-based remote candidate willing
  to overlap EU hours.

### (c) Staff / senior generalist software engineer

- **Titles:** `staff software engineer`, `senior software engineer`,
  `principal engineer`, `lead engineer`, `founding engineer`.
- **Boards:** Levels.fyi Jobs (comp-focused, staff/senior); Wellfound
  (startups, direct-to-founder); Startup.jobs; Built In (remote dev-engineering);
  Cord (direct message).
- **Remote-first employers:** GitLab, Grafana Labs, Canonical, Automattic,
  Zapier, Deel, Remote, Doist, Elastic, MongoDB, Docker, Twilio.
- **Filters to apply everywhere:** `Remote`, `Worldwide`/`Anywhere`, and
  salary transparency where available.

### Cross-cutting tips

- On Arbeitnow and Berlin Startup Jobs, use the **visa-sponsorship** filter
  first, then keyword-search; this surfaces employers already willing to
  sponsor rather than requiring per-posting triage.
- For EU onsite roles, confirm the country's route (EU Blue Card / highly
  skilled migrant / employer work permit) before applying — see Sources.
- For UK roles, check the specific employer against the **register of licensed
  sponsors** (gov.uk CSV) before investing in an application.
- For Canada, the **Global Skills Strategy / Global Talent Stream** gives
  2-week work-permit processing for engineers and computer programmers; ask
  whether the employer uses it.
