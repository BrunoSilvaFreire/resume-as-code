# Career Knowledge Base

This directory is the canonical source for personal career information. Keep detailed facts in one Markdown record and link to it elsewhere; never copy an accomplishment into technology or competency files.

- `profile/profile.yaml`: contact details, education, and certificates.
- `experience/`: companies, roles, initiatives, decisions, and incidents.
- `projects/`: independent or cross-role projects.
- `knowledge/`: reusable context that is not itself a resume claim.
- `evidence/`: references that support claims.
- `index.md`: generated by `career index`; do not hand-edit it.

The repository intentionally ships without personal records. Use `career new-record` or copy the structure from `examples/demo/career/` and replace every value.
